# 🌟 SMM Bot — دليل الإعداد والتشغيل

بوت تيليجرام متكامل لبيع خدمات SMM مع دفع بالعملات الرقمية.

---

## 📁 هيكل الملفات

```
smm_bot/
├── main.py              ← نقطة الدخول الرئيسية
├── config.py            ← الإعدادات (عدّلها أولاً)
├── database.py          ← قاعدة البيانات SQLite
├── crypto_pay.py        ← نظام دفع BEP20/TRC20
├── states.py            ← ثوابت الحالات
├── requirements.txt
├── deploy.sh            ← سكريبت النشر على VPS
├── smm_bot.service      ← خدمة systemd
├── data/                ← قاعدة البيانات والسجلات (تُنشأ تلقائياً)
├── utils/
│   ├── api_client.py    ← واجهة API موقع SMM
│   ├── keyboards.py     ← كل لوحات المفاتيح
│   ├── subscription.py  ← فحص الاشتراك الإجباري
│   └── notifications.py ← الإشعارات التلقائية
└── handlers/
    ├── start.py         ← /start والـ Deep Links
    ├── user_menu.py     ← التصفح (منصات، فئات، خدمات)
    ├── order.py         ← تدفق الطلب + /track
    ├── charge.py        ← الرصيد والشحن
    ├── message_router.py← موجّه الرسائل المركزي
    └── admin/
        └── panel.py     ← لوحة الأدمن الكاملة
```

---

## ⚙️ إعداد البوت

### 1. عدّل `config.py`

```python
BOT_TOKEN    = "توكن البوت من @BotFather"
ADMIN_ID     = 123456789          # ID الأدمن
BOT_USERNAME = "YourBotUsername"  # اسم البوت بدون @
SMM_API_URL  = "https://smmalmasry.xyz/api/v2"
SMM_API_KEY  = "مفتاح API من الموقع"
```

### 2. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 3. تشغيل البوت

```bash
python main.py
```

## 👑 أوامر الأدمن

| الأمر | الوظيفة |
|-------|---------|
| `/admin` | فتح لوحة التحكم |
| `/track <رقم>` | تتبع طلب |

---

## 🔗 Deep Links

كل خدمة مضافة يمكن ربطها برابط مباشر:

```
https://t.me/YourBotUsername?start=svc_<service_id>
```

مثال: `https://t.me/MyBot?start=svc_5`  
→ يفتح البوت ويعرض تفاصيل الخدمة رقم 5 مباشرةً.

---

## 💳 الدفع بالعملات الرقمية

1. افتح لوحة الأدمن `/admin`
2. اضغط **إعدادات الدفع**
3. فعّل BEP20 أو TRC20 وأضف العنوان والإعدادات
4. سيظهر زر الشحن تلقائياً في صفحة الرصيد

---

## 📢 الإشعارات التلقائية

- **قناة المستخدمين الجدد:** اضبطها من `الأدمن → القنوات`
- **قناة الطلبات:** اضبطها من نفس القائمة
- تأكد أن البوت **أدمن** في القنوات

---

## 🔒 الاشتراك الإجباري

من `الأدمن → اشتراك إجباري`:
- أضف القنوات (البوت يجب أن يكون أدمناً فيها)
- أي مستخدم لم يشترك سيظهر له الطلب بالاشتراك أولاً

---

## 💾 النسخ الاحتياطي

- **يدوي:** `الأدمن → نسخة احتياطية`
- **تلقائي:** كل 12 ساعة يُرسَل للأدمن تلقائياً
